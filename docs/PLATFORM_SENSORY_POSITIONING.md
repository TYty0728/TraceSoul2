# 平台与感官架构定位（大白话版）

> 2026-08-17 定稿。这是「平台与感官架构定位讨论」的结论，故意用大白话写，给以后接手的人看。
> 它是《TRACESOUL2_ARCHITECTURE_ALIGNMENT.md》第 29 节的展开；两边冲突时以总纲为准。

## 一、这个问题到底在问什么

角色（Brain）以后要接很多种「身体」：QQ 终端、控制台、将来可能的机器人身体、你的手机摄像头……

每个身体都自带一点「本地脑子」：有的会过滤垃圾消息，有的会认人脸，机器人还会自己保持平衡。问题是：

**身体自己会干的那部分活，和灵魂该管的那部分活，界线划在哪，才能既不让灵魂被身体绑架，又不强迫所有身体长得一样？**

## 二、两条走不通的路

### 路 A：所有身体强制长成一个样

规定每个身体都必须带齐同一套本地能力（过滤、摘要、认模式……），差别只在参数。

- 好处：灵魂永远面对同一种东西，省心；安全也好统一管。
- 坏处：微信这种纯文字终端被迫背一套它用不上的「平衡控制框架」；反过来，机器人的连续控制、急停、关节反射又塞不进统一模板。来一个全新身体（比如脑机接口）就得改一次框架。
- 一句话：**为了让灵魂省心，把身体都削成一样的。**

### 路 B：每个身体自己随便介绍自己

身体自己说「我会避障」「我会认脸」，没说就当不会。

- 好处：每个身体都最合身；新身体带新本事，框架不用动。
- 坏处：灵魂听到的是一堆陌生名词——A 说的「避障」和 B 说的「安全反射」是不是一回事？没人知道。灵魂会被平台的用词绑架，学到的经验换不了身体；最糟的是灵魂为迁就每个身体长出各种平台专属分支，**不知不觉又变成灵魂被平台定义**。
- 一句话：**灵魂只能选择相信身体的自吹自擂。**

## 三、我们选的：能力语言由灵魂统一，身体只填自己的实际值

不统一厚度，也不放任自报家门，而是把「自我介绍」拆成两层：

- **灵魂（框架）定义词汇表**：有哪些能力维度（反应快慢、摘要频率、认什么模式、安全反射有几类）；每个维度分几档；哪些保命能力必须存在、不许说「没有」。
- **身体填表**：我在每个维度是哪一档；我现在状态怎么样（摄像头被挡住、带宽掉、算力紧张）；我的安全反射是什么、参数多少。

落成三条大白话准则：

1. **身体自己会干的事，别来烦灵魂；干不了的，才交上来。**
2. **身体要随时说实话。** 摄像头被口袋挡住，就得说「我现在看不见了」，不许假装。灵魂按「身体此刻的真实状态」决定把活交给谁，而不是按「你是哪个平台」。
3. **保命的开关不许讨价还价。** 急停这类安全能力是框架强制项，身体不能说「我这台没有」。

注意：这三条里，**今天真正用得到的只有第 1 条**。现在只有 QQ 和控制台两个身体，都是「会干一点点活」的级别，没有保命开关。第 2、3 条是给「第二个身体出现那天」预埋的规矩，到时再细化。

## 四、现在代码里已经长什么样

### 已经落地（都能在代码里找到）

- **身体远近**：物理身体（小机器人 / 大机器人 / 娃娃）近过自己的软件（以后的复杂 app / 虚拟人物 / 游戏），再近过文字聊天软件（QQ 等），控制台是最低的文字壳，不算自己的软件。同层才打分；家里等身在，不拿小娃娃当嘴。
- **器官和下滑**：说话（文字/语音）才改「激活的身体」。发图、发视频只是那只器官往更远、长了它的身体下滑，整段对话不搬家。
- **贡献表声明** `BodyId / BodyTier / Organ`；没声明的旧插件仍按 id 猜测。入站器官写在事件上，不写进 Moment。
- **灵魂永远看同一张能力表**：每个能力都用同一张表格描述。QQ 发文字和表情包在表里长得一样。
- **表是活的**：身体断连、没配 api_key、图库是空的，对应条目自动从表里消失。
- **平台规矩平台自己带**：发完怎么合并成一条 QQ 消息等由平台插件挂进来。
- **最终开口内容归灵魂**：插件绝不替他决定说什么；落在哪具身体、哪只器官上由硬逻辑算。

### 还没做（并且现在都不着急）

- 定位、抱起、共视/共听、他自己身上的摄像头——传感还没接。今天激活身体靠「她在哪说话」。
- 「本地能干多少活」还没正式分档命名。**等真有第二个身体了再定名字、再写进代码。**
- 「降级」还没有，只有「有 / 没有」。
- 保命开关还没有强制校验。

## 五、用例子说

- **机器人身体**：自己能抬腿走路、保持平衡；遇到「疑似认识的脸」才喊灵魂。
- **手机监控**：本地只筛「画面有没有动静」，有动静才报给灵魂。
- **微信终端**：啥也不干，来什么转什么。
- **现在的 QQ 终端**：连接桥只收发（来什么转什么）；表情匹配、语音情绪这些在插件本地做，灵魂只给关键词。

它们不是四种架构，是**同一张能力表上填了不同的行**。

## 六、「感官」是什么，现在有哪些

感官不是按「音频 / 图片 / 视频 / 文字 / 触觉」预置的一排器官，而是**翻译器**：把外面的事翻成 Moment 给灵魂，或把灵魂的一句话翻成平台能发的东西。

- **输入感官（把外面的事翻给灵魂）**：现在有 QQ 文字消息、控制台文字、时间调度到期。
- **输出感官（把灵魂的话翻出去）**：现在有发文字、发表情图、发语音（TTS）、发图（生图）、发空间说说。

以后摄像头来了，就是加一个「视觉翻译器」：它把画面翻译成「她回来了」这样的 Moment 事实，而不是让灵魂去啃像素流。触觉同理。**灵魂不需要长耳朵和眼睛，它只需要「发生了什么事」。**

## 七、红线（不许破的规矩）

1. 灵魂是根，不迁就身体；身体是异构的，不削成一样。
2. 词汇表只有一个来源：灵魂。身体只能填表，不能发明新词。
3. 保命开关不在填表范围内，是强制项。
4. 状态必须随时说实话，路由永远归灵魂。
