## 真实监听的生命周期

- 用户明确点击连接：按已有设置，可随后开始后台名字监听；未录声纹时只连接。也可手动点击开始/暂停。Host启动或重启不会自动开始监听。
- 新网页只发开始/暂停指令并读取状态，不再逐句请求采音或代为提交语音Moment。
- 刷新、离开或关闭网页仅停止页面轮询，**后台仍继续采音**。重新打开会附着到同一个后台状态，不新建第二个会话。
- 需要结束时明确点暂停。停止请求立即封闭新准入并取消对应采音，迟到结果作废；已开始的回复可以收尾。收尾期间不能再次开始、重录声纹或切换音色。
- 网页断线不代表停止成功，页面保留“结果未确认”的提示，恢复连接后核对。过期的monitorId不能停止新的后台会话。
- 关闭设备会先暂停、等待收尾，再结束会话。插件关闭也请求取消正在进行的采音。Host关闭时取消等待并回收后台任务。
- 采音、唤醒、模型或交付失败会停止任务，保留明确错误类别，不自动重新开始、重发Moment或重复播放。

名字应答与30秒窗口仍见[名字与拼音](WXXZ_WAKE_NAMES.md)。短名字可仅固定应答；真实指令仍要求整句本人声纹。QQ与其他会话的输出边界不变，设备交互专注不更改Soul的持久睡眠/心跳状态。

## 锁与音频

后台USB/VAD/ASR等待不占Soul运行锁。采音返回后，进入该锁检查会话、名字、声纹和一次性凭据；真实准入后复用PostInput/Kernel主链。停止标记与会话标识在准入时再次核对，不能由网页伪造后台凭据。

另设设备音频互斥：采音与板端语音播放不能重叠，包括其他WXXZ主逻辑输出。播放时暂停采音；普通监控等待不会阻塞控制台和QQ主逻辑，实际WXXZ输出仍可能等待当前有界采音收尾。

## 调试数据与接口

调试面板显示后台阶段、30秒专注倒计时、原始听写、规范文字、目标拼音与匹配方式、声纹分数/是否确认、准入原因和主逻辑处理完成情况。admitted表示听写核验后已交给主逻辑，turn_completed表示本轮处理及所需交付完成，不能把沙盘结果或设备回执当成实物听感验收。

诊断最多40条，每项原文/校正文本最多500字，仅在Host内存保存；清空不会删Moment或改声纹。未准入语音只在鉴权调试页可见，不进入主模型，不追加到磁盘诊断日志。不保存PCM或声纹向量，不把供应商错误正文/Key复制进诊断。轮询不会覆盖未保存的名字/音色草稿，也不会反复重建未变化的诊断详情。

均沿用控制台鉴权：

- GET /wxxz：原状态加monitor、diagnostics；监控阶段与设备专注状态分开。
- POST /wxxz/monitor/start：{sessionId,wake}，启动唯一Host任务。网页请求结束不撤销已明确请求的启动。
- POST /wxxz/monitor/stop：{monitorId}，返回停止中/已停止的真实状态；省略编号表示管理员明确停止当前任务。
- POST /wxxz/attention/preview：{text,focused,speaker}，speaker为owner/unknown/short，仅沙盘假设。
- POST /wxxz/diagnostics/clear：仅清空内存诊断。
- 旧call/start/listen接口保留显式客户端兼容；后台拥有的通话拒绝网页重复驱动或代提交。旧call/stop可停止对应后台通话。
