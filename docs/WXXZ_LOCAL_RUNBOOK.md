# WXXZ 本地主链联调

2026-10-16：管理员模拟明确发言和真实板载麦克风 → 电脑本地 SenseVoice 听写 → WXXZ Moment → 现有 Kernel/Agent → WXXZ 文字显示与系统测试语音均已现场验收。真实录音使用固件 0.2.0。摄像头、背景 JEV 准入、自动调度、角色音色、图片生成和视频仍未接入。

## 使用

1. 启动 USB 桥（见 [SensoryBoard](../Tools/SensoryBoard/README.md)），确认本机 5089 可检查连接。
2. 使用本次构建的 Host，沿用原家目录、管理员账号和小汐角色。在「对话」页选择 WXXZ。
3. 按实际受众选择「本人私密现场」，然后点「连接 WXXZ 会话」。未确认私密时按公开现场处理。此入口是已登录管理员模拟本人发言，不能据此声称真实音频中的说话者已被识别。
4. 输入明确发言并发送；它不经过 JEV。回复使用现有主模型和公共上下文装配，增加 WXXZ 场景说明；当前提示通常一两句、60字以内。WXXZ 使用独立会话原文窗口，主体身份/记忆仍走既有授权视图。
5. 页面分别显示屏幕传输和音频执行结果，展开「设备回执」查看具体结果。控制页预览不是实物截图，完成回执也不能替代人眼/耳确认。

### 麦克风听写

先按感官终端说明安装可选本地 ASR，确认桥的 `asr_ready=true`、固件为 0.2.0。连接 WXXZ 会话后，清空输入框，点击「录音 8 秒并听写」，看到正在录音后对板子说话。结果仅填入输入框，核对后点「发送一个 Moment」才唤起主模型；静音、空结果或错误不会自动提交。当前每次手动录音，不是持续监听、自动唤醒或 VAD。

`/wxxz/listen` 在现有主体运行锁中执行；返回的 `captureId` 绑定当前会话及原始听写，发送时只可消费一次，关闭/重连会话即失效。未经编辑的已核验结果以 `board_final_transcript` / OrganVoice 进入；编辑后清除标记，改为管理员手动输入，不伪称原始听写。音频内容不落盘，识别不确认说话者身份；受众设置仍由管理员声明。

本次 Host 构建、完整 ChatCheck、WXXZ/页面专项和21项 Python 检查通过。真实采集取得8秒/768000字节完整回执；首次现场ASR仅返回标点，未提交。用户直接点击按钮后第二次识别得到完整测试句，识别约191ms（不含录音及传输），角色名出现同音误字；保留原始转写发送，真实主体回复后板端画面/两段语音均完成，用户确认屏幕和声音正常。尚无连续多轮、远场/嘈杂环境、打断和延迟优化验收。

WXXZ 的输出不退到 QQ，QQ 不使用 WXXZ 器官。首版只提供一个 WXXZ 文字表达器，在屏幕完成后对同一文本合成本机系统语音；语音完成另记运行回执，显示成功只保存一份语义回复。屏幕失败不记成已表达；屏幕成功而语音失败仍保留实际显示的文字，明确报告语音失败或未知。

首版绑定单个本机 USB 桥 `127.0.0.1:5089`，不是公网设备接入接口。Host 使用不带系统代理、禁止跳转的固定回环连接。`/wxxz`、`/wxxz/session`、`/wxxz/moments` 沿用控制台登录与同源保护，不能上传任意平台/设备/受众字段改变输出。会话重连或关闭后旧会话不可投递；同一会话内请求编号去重（最多256条后需重连）。重启不会恢复旧连接，页面刷新后需重新连接。

物理发送开始后，即使浏览器断开，也会在有界超时内等待回执，再释放主体运行锁，避免播放中途换会话。当前为顺序播放，尚未实现随说随播、打断、离线队列或跨设备路由。

## 系统测试音色

USB 桥增加 `POST /api/speak`，由 Windows `System.Speech` 的已安装 zh-CN 音色合成 PCM16/48kHz 单声道，按不超过8秒的段发送给板子。只在本机临时目录合成，完成后清理；不调用云 TTS，不代表角色音色。缺少中文系统音色或合成失败时明确报错。

固定 .NET 合成代码与输入 JSON 分开传递，用户文字不拼进 PowerShell 代码；无需修改系统执行策略。最长500字、合成超时90秒、合成结果最多120秒，板端任何分段结果未知都不会自动重播。
