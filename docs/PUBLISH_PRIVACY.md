# 发布中的运行数据边界

2026-10-20核对了公开main、43个公开版本标签及v0.1.48三个公开安装包。未发现私人图库原图、运行数据库、声纹、参考音频或私有配置文件；身份卡使用通用空白模板。仓库唯一图片是此前授权公开的项目群二维码。

经用户明确授权，公开main及43个旧版本标签已改写为不含该默认地址的历史；42个旧正式版本的126个安装ZIP及126个摘要已撤下，保留不含该插件的SDK包。旧版本的提交标识随之改变，已有克隆应重新克隆或把未提交工作迁移到新历史，勿合并或再次推送旧历史。v0.1.49提供清理后的安装包。

以上处理覆盖本仓库公开分支、标签和发布资产，不能撤回第三方克隆、下载副本或GitHub按旧提交标识保留的缓存。GitHub缓存、PR引用和服务端垃圾回收需要按其敏感数据流程联系GitHub Support处理，不能据此声称旧内容已从所有位置消失；见[GitHub官方说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)。本地恢复备份在仓库外私密保留，不应上传。

公开测试、文档仍有少量角色名和音色标识示例引用，它们不等于人物档案正文、图片或原始音频，本文不声称已完全匿名化。不要将实际角色档案、私人对话、机器地址或凭据写入文档。

Git与Docker排除角色运行目录、图库索引和设备私密配置；发布检查拦截被强制加入的运行目录、数据库、声纹、语音/Wi-Fi私密配置，并拒绝在QQ语音源码及清单中重新内置服务地址。报告只输出路径和类别，不输出具体内容。通用身份模板仍可发布。
