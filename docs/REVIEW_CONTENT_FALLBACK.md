# 复盘细节的并发保存与内容拒绝兜底

## 2026-10-24 现场核对

远端实际安装0.1.68。23日复盘于北京时间24日04:00、09:53两次开始，分别在04:03、09:54停止，阶段均为“细节生成”，迁移错误为`not an error`。两次堆栈均指向`SqliteMemoryManager.SavePluginDocument`的草稿保存，底层为共享的SQLite预编译插入语句；四路细节任务可以同时使用该语句。现有证据不能把这两次停止归因为限制词。

在独立进程取得主库和迁移库一致快照，`quick_check`均为`ok`。快照中23日来源进度含387条Moment，24批事件观察及28条细节完成检查点保留；22日状态为done。本轮没有恢复正式任务、清除保护、替换服务器程序或调用正式模型。快照检查不是字节级历史对照，也不能据失败列表的0计数推断丢失。

## 0.1.70 行为

- 细节草稿改走`MigrationDb.SaveProgressDocument`现有写入锁，与事件/细节提交共用同一条受保护的主库写入连接。四路模型请求保留并行；调用留痕表的共享插入也单独加锁。来源读取与版本校验继续保留。
- OpenAI兼容响应识别明确的内容审核错误码、`finish_reason=content_filter`及非空`message.refusal`；Gemini原生识别安全阻断。异常仅带固定脱敏说明，不把拒绝原文带到上层。不因敏感词出现在正常事件中就跳过。
- 对当前写作请求的明确自然语言拒绝直接停止该次结构纠正；细节JSON中的拒绝也不能当成记忆正文。识别要求拒绝当前任务的句式与请求/政策语义，不把一般否定、引语或“审核”等单词当成拒绝。
- 细节生成或超长重写被拒绝时，保存与来源指纹绑定的拒绝标记，沿用该条已保存、已验证的事件短句作为细节阅读正文；同批其他条目继续。拒绝标记、最终完成标记和调用留痕可以追溯，拒绝话术不写入事件记忆。
- 重启或后续阶段失败后，沿用已完成细节及拒绝标记，不重复请求被拒的同一项。来源/身份改变仍拒绝复用；事件正文、原始Moment及引用不因此删除或改绑。
- 复盘通道把内容拒绝交给当前处理项决定，不预先发通道故障通知；其他未处理的复盘失败仍由日构建工作器报告。普通对话的错误报告保持。

本次兜底针对有已验证事件可保留的细节阶段。其他阶段的内容拒绝仍保留明确错误，不凭空构造事件、认知或身份正文。鉴权、余额、限流、超时、服务故障、取消、坏JSON及来源校验错误都不作为内容拒绝跳过。升级不自动重跑失败日期或解除暂停。
