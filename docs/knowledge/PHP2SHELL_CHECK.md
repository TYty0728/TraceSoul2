# PHP2Shell 服务器检查

## 2026-10-22 检查结论

针对 CVE-2026-109618、CVE-2026-109619，只读核对现有 TraceSoul2 服务器和 New API / Decisions 中转服务器。当前运行服务未发现 PHP 运行环境或 PHP 请求处理入口，因此没有发现这两项漏洞的适用组件，无需为此停机或安装 PHP 更新。

| 范围 | 核对结果 |
|---|---|
| TraceSoul2 应用 | ASP.NET Core / .NET 8；Nginx 转发到应用 |
| 两台宿主机 | 已安装软件包、常见解释器路径、服务单元和实际进程未发现 PHP 运行时 |
| TraceSoul2 服务器容器 | 运行中的 tracesoul2、napcat 均未发现 PHP 解释器或 PHP 软件包 |
| 中转服务器容器 | 运行中的 new-api 未发现 PHP 解释器或 PHP 软件包 |
| 实际启用的 Nginx 配置 | 从主配置递归解析 include；未发现 PHP / FastCGI 后端，两台均无不可读配置 |

Nginx 安装附带的 `fastcgi-php.conf` 模板均未被实际配置引用。中转服务器的 `phpcalls-bpfcc`、`phpflow-bpfcc`、`phpstat-bpfcc` 是诊断工具，不是 PHP 解释器。

检查通过现有 SSH 连接完成，以管理员权限读取系统与容器信息；未升级软件、部署代码、重启服务、修改服务器配置或读取聊天数据库。已停止的 astrbot 容器未启动，也未检查其内部组件；本结论覆盖当前运行服务，不代表入侵排查或整机安全审计。

将来新增 PHP 网站、WordPress、phpMyAdmin 或附带 PHP 的面板时，需要重新检查。官方修复版本为 PHP 8.5.12、8.4.27、8.3.36、8.2.35，发行版也可能通过回移补丁修复；应按实际运行分支和发行版安全公告确认。升级容器内 PHP 时，需要重建或更新镜像并替换运行实例，不能只更新宿主机。

参考：[PHP 官方安全公告](https://www.php.net/archive/2026.php#2026-10-21-5)。本机脱敏检查证据保存在运行资料目录，不将服务器地址、凭据或机器绝对路径写入源码知识库。
