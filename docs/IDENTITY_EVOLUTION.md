# 自动复盘的认识演化（0.1.65）

## 行为

日构建及显式identity.review共用认识演化流程。新证据、措辞变化和认识变化分别处理；每日感受独立写入，不要求每天改身份正文。

1. 认知create/revise只是待写入候选。按候选自己的含义再次语义检索旧认识，模型明确判定同义印证、实质修订、独立新理解或仍属经历/依据不足。同义候选转为原节点reinforce，复用原正文/范围/例外；多个同义候选合并证据。不同对象、条件与反证不因向量相似自动合并。此比较同时用于私密日构建和公开分环境整理。
2. 身份来源绑定含义指纹：正文、对象、范围、例外、状态、最后反证及来源环境；新证据使普通版本号增加，不再自动使身份卡过时。分享批准仍绑定精确版本。旧引用只有在旧精确来源仍匹配时才可迁到含义指纹，已过时引用需要语义判断重新确认。
3. 全量读取当前可用私密身份认知，分批归并理解并核对每个来源ID；跨批再归并同义认识。条件、例外、反证和确定程度保留；经历细节另列。分批结果有检查点，含义未变时复用归并结果。
4. 新证据按归并认识统计独立支持、反证、自我复述与关联；同一Moment不因多个同义节点重复计数。模型读取前后证据摘要，原始证据仍在库，输入不随历史证据条数持续增长。随后经过变化判断：unchanged/changed/insufficient。unchanged不成稿；已有理解和证据均未变时连身份模型也不调用。changed必须给出不同的前后认识、变化种类及有效依据。
5. 只有需要更新时才从完整当前认识成稿。写作请求不带旧正文，切断递归摘要；旧卡仅出现在先前的变化判断中。正文保持300字符目标/600字符上限，但长度只是结构边界，不承担语义去重。
6. 认识状态、派生卡、来源及旧卡历史在事务内提交。正文过长只保留该项待整理，续做只重新成稿；本版已提交的其他卡和内心不重复生成。旧卡首次进入新流程会建立认识基线，只有判断存在实质变化才重写。旧版卡片pending进入新流程，不再对旧长草稿循环压缩。核心事件、认知、排序和归档检查点继续使用原有保护。

当前身份阅读视图同时采用经核对的归并结果：同一理解的历史同义节点不重复注入；被分类为经历细节的材料继续可查证，但不冒充身份认识补在卡后。公开视图只有在组内所有来源都可读时才能展示该归并认识。归并的来源或卡版本变化后旧视图失效。

## 反证和旧资料

被削弱的认识仍参与理解归并，但必须呈现反证及不确定性。旧的确定正文在来源被削弱后失效，不能用unchanged直接恢复；明确形成的新认识可绑定当前weakened依据。再有支持证据也不能抹掉反证历史而让旧投影自动复活。历史节点、原始经历及证据保留；本版不根据文字相似度批量删除或合并旧图节点。

旧版仅因版本号变化而过时的卡，如经模型确认含义保持贴切，可用明确给出的当前依据重新绑定原正文。尚无有效认识时，不制造一张身份卡填满输出；原始材料继续保留。人工固定的人格、档案和卡片仍受保护。

## 调用与恢复

create/revise候选增加一次写入前语义比较；已是reinforce/无变化的批次不增加该次调用。身份第一次需要处理存量认识时会分批归并，其后含义未变复用结果；新证据只做变化判断，需要修改才写正文。每日内心独立一次生成，超长仍用原有一次有限补写。接口底层有限网络重试维持原设置，不增加无限重跑。

私密日构建的候选认知在语义比较前保存，后续失败可复用。身份的归并、变化决定、成稿和提交分别保存；来源、卡片或证据改变时不复用旧结果。发生真正调用/结构错误仍停止日构建，正文超长保持pending，不冒充整日成功。升级不自动补跑历史日期或解除日构建暂停。

## 验证和边界

受控模拟模型验证1500条证据仍只送有界摘要、正文不增长；连续30天提供独立印证：31条证据、1条认知、同一身份正文和版本；无变化时零身份请求。覆盖同义create转reinforce、真实条件修订、反证削弱及新开放认识、反证后旧投影不复活、旧版引用经确认重绑、40条以外/跨批来源、细节与旧同义节点不重复注入。实际Migration入口覆盖逐卡提交、网络中断、成稿pending跨实例续做、每日内心独立、无变化跳过及人工修改冲突。

这些回归验证控制流程和保存边界。语义等价、实质变化及确定程度由复盘模型判断；程序不能证明任意API模型的语义结论正确。正式模型效果仍需观察真实日构建，未用正式角色调用模型或写回资料来验收。
