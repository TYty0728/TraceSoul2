# 四领域拼图与当下 runtime

2026-09-26 源码接入，纳入产品 0.1.16、PluginApi 1.6.0。本文件替代旧认知网清单的三层模型岗位前提；正式资产状态见 [版本说明](RELEASES.md)。

## 在整体架构中的位置

2026-09-29 用户重申：完整存在由“经历与认知的完整拼图 + runtime + 衔接与运行逻辑”构成。本文件是已实现认知部分的说明，不代表完整人格拼图已经补齐。身份卡是有来源的摘要入口，现已接通认知版本与源修订失效。白天先存当下切片，深夜整合全天经历与感受，再据证据形成理解；不能把认知体系、身份卡和 runtime 作为三个顶层部分。设计见 [完整存在架构](EXISTENCE_ARCHITECTURE.md)，当前实现与检查见 [实施记录](EXISTENCE_IMPLEMENTATION.md)。

## 数据组织

长期拼图有四个理解领域：`user`（他）、`world`（世界）、`ass`（我）、`relation`（具体关系）。沿用已有 LifeRoute 域键，同一认知可以属于多个领域。记忆、事实、认知和人格是内容类型，不是四个互斥领域。未分类的旧认知显示为待分类，不按猜测批量归类。

- 原始 Moment 保存输入/表达的来源与语义，事件索引和细节用于定位与召回经历。
- Cognition 保存可修订的理解、领域、具体对象、范围、例外、置信、强度及版本；证据连接到真实 Moment 或有真实来源的 Fact。
- IdentityCard 保存来源、人工固定状态与认知版本引用；成长摘要只用有效依据，源修订/削弱/退役后退出当前视图。人工固定的内容不被自动覆盖，普通轮次不改身份。
- SubjectRuntime 保存连续主体状态，InnerRuntime 保留环境局部场景/关系；RuntimeSlice 白天追加当下状态与轨迹，RuntimeDayReview 深夜整合当天痕迹。生活状态、定时安排和设备账本沿用原职责。

当前接入以认知关系、真实经历和当下切片为基础，身份经同源投影视图加载，事件记忆保留向量检索入口；夜间回望以主观痕迹参与统一召回，不强制迁入同一张表。

## 运行闭环

当前事件 + 最近聊天（若开启）+ 仍有效的注意 + 当前生活活动 → 预召回 → Agent 同次判断 → 回应/行动/等待 → 真实反馈及 runtime 更新。资料不足时通过 `memory.recall` 查询，不额外增加固定认知或表达模型阶段。

预激活与显式查询都可独立读认知，事件索引或细节为空不再阻断认知。候选由现有 Tag 路由、Cue、文本双字片段近似和有效 runtime 引用提供，再做一次有界关联扩展。2026-10-01 未发布改动：日常预召回直接呈现复盘保存的认知正文、领域、范围、例外、削弱/冲突状态和依据来源性质；原句与原始记录 ID 留待主动 `memory.recall`，查证时最多分别展示一条支持、一条反证的原文片段和来源。认知 ID 仍供 attention_links 使用；置信数值继续参与内部排序，退出阅读层。退役、被替代或旧 `revised` 节点不作为有效理解返回。

相关事件直接展示复盘保存的事件总述与命中条目的完整摘要/细节，同一事件归组，固定日期标作事件起点，保留情境与当时感受；不为注入再次总结或截断已保存正文。日终回望单列并标明日期和主观性质。公开预召回使用可见的认知与本环境回望，近期原话只在历史窗口或主动检索中出现。相关数量和预算仍按候选选取，不是全日材料全量注入。

证据读取为后来的反证保留独立额度，不被累计支持证据挤占。相关反证不因与当前理解冲突而降权，预算允许时优先给一条相关反证候选留位置。无结果保持空，不把最新认知默认当成最相关认知。

Agent 可输出 `attention_links: [{attention: "与 attention 完全一致的片段", cognition_ids: ["本轮召回的认知ID"]}]`。内心只接受本轮实际呈现过的 ID，持久化为 `cognition:<id>` 引用。下一轮有效注意可据此延续；注意失活后不再靠引用续命。引用表示思绪来源，不是认知被新经历证明，也不提高置信。

## 长期形成与修订

2026-10-12：认知是从真实经历中形成、可随新依据修订的理解，帮助此后更准确地理解他者、自我、关系或世界。一条通常用一两句自然中文说明理解与必要原因/条件，认识的确定程度与依据相称，初步体会保留发生情境。具体经历由原始证据承载；600字是程序长度上限，原有空数组结果继续有效。

同日按用户纠正重写取材说明：以内容本身的正面意义描述任务，撤回此前具体话题的禁写清单。身份摘要承接逐渐形成的自我、他者、关系与表达认识，意义来自真实经历中的表达、选择和反馈；筛选与成稿按候选对相应认识的作用取舍，将变化融为连贯的当前理解，每个细节服务于理解的准确和完整。证据引用、隐私和长度等程序契约继续独立校验。身份候选超过预算时允许空选择（含单项尾批），较小候选直接进入成稿比较；保持原样也是完整的复盘结果。

私密日构建、历史回填与公开环境复盘都在每批生成前执行 `CognitionReviewRecallLogic`：先按环境/可见性及 active/weakened 状态过滤，再取最近更新的至多5000个候选，用现有本地BGE编码本批原文和当下切片，语义比较正文、对象、范围与例外。96字符重叠窗口覆盖长材料，不只编码开头；节点向量按模型、内容散列缓存，正文变化后重算。候选每片段取至多3个近邻（余弦至少0.45），分名次按相似度选取，重复片段不累加权重；最终最多12条、序列化正文约8000字，完整条目入选，不截断。

生成模型现在能看到召回认知的完整正文、条件、状态与版本，不再只看最近40条的对象名称。相同认识获得独立新依据用 reinforce，实质变化用 revise，反证可 weaken，确实独立的新理解才 create；重复依据或无变化不操作，相似话题不自动合并不同对象/范围。向量只提供候选，不决定写入类型，不新增LLM筛选调用。每批提交后重新检索，修订旧版退出候选，新版可被下一批使用；检索/模型校验失败不将本批当成空结果继续写入。升级不会批量清洗或重写已有认知。

日构建逐批覆盖当天完整原始 Moment，并附上对应当下切片，要求逐条 `evidence_moment_ids`。切片本身不等于外部确认，不能代替真实经历原件。未展示 ID、无证据操作、未知领域/目标和不合法参数在结构校验时拒绝，沿用一次纠正机制；数据库再验证来源存在，批次失败事务回滚。正常日构建不再把所有变更挂到最后一句。

兼容旧直接写入接口：仅完全未指定证据时，可使用存在的触发 Moment；显式错误证据不能回退。新日构建禁止省略证据。

| 操作 | 行为 |
|---|---|
| create | 新理解；正文上限 600 字，可多领域，不再强制 19 字或依赖已有 Tag |
| reinforce / weaken | 增强/削弱，证据为 supports/challenges；相同证据重放不反复改变强度 |
| revise | 新建版本，旧版标为 superseded，保留 revises 边和反证 |
| retire | 标为 retired，保留经历和历史 |
| link | related_to、abstracts、exemplifies 或 contradicts；关联依据单独标记，不自动增强节点 |

认知增加 `ContextConversationId`、`MemoryVisibility`、`SubjectKey` 与可选 `IdentitySlot`。环境与参与者由原始证据计算，分享批准由控制台绑定当前版本，模型不能自行升级可见性。单项操作的依据与目标必须同环境；公开经历独立整理。

日构建每批最多三项变更。同文、同领域、同对象/范围/例外的有效节点（含已削弱节点）再次 create 时合并证据，不重复建节点，也不自动恢复为活跃。SQLite 增量迁移字段，不清空原始经历、旧节点或证据。新增可选 `ICognitionGraphStore`，既有 `IMemoryStore` 实现无需强制增加方法。

## 预算与边界

- 日常对话召回读取至多5000个最近更新节点；文本兜底是双字片段匹配，既有Tag语义路由继续可用。上文新增的本地认知向量检索用于复盘前比较旧认识，尚未替换日常对话召回。
- 一次认知拼装不超过 3200 字（含标题），候选数量服从调用预算；零预算为空，超长首项不突破限制。事件记忆使用其原有预算，不是全上下文合计 3200 字。
- 日构建每批原始证据不超过 200 条，原文与对应切片共同计入约 24000 字预算，按时序分批覆盖整天并保留完整消息。单条超预算时失败保留，不静默跳过后标整日完成。历史回填从已有事件关联的原始 Moment 取证，不推断丢失来源。
- 代码校验证据存在性、引用边界和修订规则；模型解释是否合理仍需实际效果评估。聊天里的计划不证明物理动作完成；Prompt 保留来源/证据类型并区分计划、表述、虚构和执行。
- 人工卡及无来源旧卡没有重建成图节点；日回望候选最多1000条，与认知共用3200字召回预算。跨环境认知自动合并、无限历史全量图搜索和外部设备驱动不在本次实现内。
