# 开发板触屏通话

2026-10-20：代码与模拟检查完成，固件版本0.4.3；尚未刷写、启动真实通话或取得本版实物验收。昨天0.4.2的充电宝开机、触屏菜单和偏好保留仍是实机基线。

## 使用流程

1. 载入新版Host、连接桥和0.4.3固件；沿用原角色、声纹、Wi-Fi证书与语音配置。
2. 在已登录WebUI「身体与感官 → 小智开发板」勾选「允许开发板触屏开始／结束对话」。这只授权按钮，不开始采音。Host每次重启默认未授权；关闭网页不撤销本次授权。
3. 板子上方出现「开始对话」，右上角保留设置入口；没有有效控制连接时按钮灰显，主页提示去电脑授权。首次配网提示仅在未配网时出现。
4. 点开始后，板子提交带启动代次和序号的请求。Host创建真实WXXZ会话及后台通话、再次向板子确认同一请求，之后才开始采音；若确认途中点结束，开始不能继续。沿用VAD、整句本人声纹、ASR、`我听见` Moment和原路图片/字幕/TTS输出；本按钮为直接通话，不要求再次喊名字。
5. 点结束立即在板端暂停麦克风、打断当前播放并阻止后续音频块，随后由Host取消后台通话及迟到输入。已交给主模型的计算可能继续收尾，但不因此重新开启采音或播音。新通话要等旧后台收尾，再次点击开始。

自动新建的是公开现场；只有管理员已经明确打开私密WXXZ会话时才保留该现场设置。设备按钮不能自行声称主人身份、私密受众或切换到另一角色。

## 控制链路

```text
已登录WebUI授权 → Host后台控制循环 → 连接桥 → USB或已配对TLS开发板
                                        ← 启动代次＋按钮序号＋开始/结束
物理开始 → Host会话创建 → 同代次确认 → 原WxxzVoiceMonitor
```

Host主动访问桥的`POST /api/device/control`；板子不持有控制台Cookie、模型Key，也不匿名调用Host接口。桥复用USB或证书/令牌校验后的TLS连接，不新增公网监听。非回环桥继续使用原私有HTTPS与Bearer配置，容器内默认不授权、不访问硬件。

控制租约以Host本次授权随机标识区分，板子同时只接受一个未过期控制方，45秒没有有效同步会失效，需停止采音和播音；开启触屏诊断时同样执行到期检查。当前媒体链路独占设备连接，控制同步可能在一次有界采音后返回，因此结束首先在本地驱动生效。授权撤销尝试主动释放租约，失败则等待过期；不能用更换地址宣称完成Soul服务器配对。

初次授权、板子重启、控制传输结果未知后的重连只建立新的按钮基线，不执行此前的开始事件。已处理序号先记账再执行，失败不自动重试开始。重连不会恢复通话；要重新按开始。结束/暂停不依赖电脑锁；GUI点击本身不创建触觉Moment。

菜单仍保留亮度与本机麦克风权限。显式点开始会请求允许采音；播音必须等Host确认通话后恢复，旧通话正在收尾时不能借新开始恢复旧音频。菜单中的「允许麦克风」是显式本机权限恢复，本身不创建通话。
