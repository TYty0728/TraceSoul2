## 电脑预览

在已安装Pillow/pyserial的感官终端Python环境运行：

```powershell
python Tools/SensoryBoard/bridge.py --preview-only --http-port 5090
```

打开`http://127.0.0.1:5090/`，可切状态、编辑名字/字幕、模拟专注秒数并逐页查看。这里与实机输出使用同一个Pillow渲染器，按原生320×480显示，仍不是实物照片。`--preview-only`不实例化Board，禁止COM/ASR参数，设备API均409。仅绑定回环，保留Host/Origin校验，无模型调用。关闭网页不停止预览进程，Ctrl+C结束。

导出PNG（不启动HTTP服务）：

```powershell
python Tools/SensoryBoard/export_display.py --output-directory <仓库外预览目录>
```

## 接口与兼容

- `GET /display`：真实桥也可打开纯预览页。
- `POST /api/display/preview`：`{state,name,subtitle,page,remaining}`，只返回PNG/布局，不访问USB。page从0开始，字幕最多500字，remaining整数0～30，无效值400。
- `POST /api/display`：同一请求，将指定一页作为RGB565完整画面发到板子，返回真实frame回执与相同预览；仅真实USB桥可用。

结果含page/page_count/font_size/width/height/caption_lines/preview_only。分页保留全部文字和显式空行；一次只发指定一页，page_count不代表所有页面已经显示。既有`/api/text`、图片/音频协议和固件保持兼容。
