## 定义

环境是 runtime 的通用事实，不是 QQ 群对象，也不由聊天正文或模型决定。

| 场景 | 环境 |
|---|---|
| 已绑定的专属用户与主体单独相处 | private（私密） |
| 其他人与主体单独交谈 | public（公开、不具有私密权限） |
| 专属用户也在场的群聊 | public |
| 身份或受众未确认 | public |

本地受控对话入口代表专属用户；外部平台必须绑定真实账号。昵称、群名片、自称身份不能建立权限。公开并非互联网可见的同义词，而是相对于两人私密关系的边界。

平台提供 `EnvironmentObservationData`，内核在每轮开始计算不可变的 `EnvironmentSnapshotData`。内容包括平台、机器人账号、会话及根对话、当前发言者、已观察参与者、本人是否在场、是否直接对主体说话、引用事件、受众是否确认和可见性。群中观察到的账号不是完整成员或在线名单；引用仅有 ID 时不猜测原文和作者。

## 数据流与所有权

1. 平台适配器报告结构化观察。`EnvironmentLogic.Resolve` 结合绑定身份和受众事实计算边界；外部事件不能伪装成本地平台。
2. 每轮 `TraceTurnContext.Environment` 固定本轮环境，原始 Moment 同时保存 `EnvironmentJson` 和 `MemoryVisibility`。
3. 私密使用原根 ConversationId；公开按平台、账号、会话生成环境作用域。不同公开会话的历史、约定、工作状态和执行账本分别读取。
4. 根 runtime 记录最近的在场环境；私密后台目标独立保存，群消息不会覆盖它。定时任务和持续执行记录创建时的环境；恢复时重新核对身份绑定。
5. 输出按本轮原始目标和机器人账号发送，文字/表情暂存也归属各自轮次。已有环境时禁止回退到“最近一次 QQ 会话”，显式参数也不能改投其他接收人。解绑后旧私密目标失效。

主体状态由 `SubjectRuntimeLogic` 连续保存，公开交流的感受可接回同一主体；每个感受、心情和关注各自保留来源。跨环境只延续允许的内容或有限总体情绪，不透露私人原因。局部场景、关系视角、生活调度与发送目标保留环境边界；旧轮和日复盘不能覆盖较新主体状态。

## Prompt 注入

`RuntimeContextLogic.State` 是当前状态的唯一视图，Agent、兼容 Mind 和显式润色共同使用：

- 时间与近期计划；
- 当前环境、发言者身份、交流方式和受众；
- 可见的生活状态、共同文字场景、状态、上一刻感受、情绪与有效关注；
- 距离上次本环境交流的时间，以及私密环境的今日新识和当天轨迹。

时间 facet 只负责时间与计划。`identity.base`、`inner.snapshot`、`day.trajectory` 不再先生成再重复注入；状态视图直接读取所需数据，保留原有写入通道。空状态不占提示，其他插件观察按正文去重。触发原因由 `RuntimeContextLogic.Trigger` 单独说明，避免把群中旁听当作后台事件。动态观察也已移出润色的稳定角色段。

`IdentityProjectionLogic` 为所有环境生成同源身份视图：人工卡、有效的认知派生摘要及带身份用途的理解。公开只使用当前环境可见内容和本人明确批准的当前版本；批准摘要不公开原始证据，修订后旧批准失效。旧 `PublicIdentity` 兼容字段现在为各环境共同自我描述，私密也使用。历史与约定仍按环境读取；旧动态插件钩子无可见性契约，公开不调用。

## 能力边界与兼容

PluginApi 源码版本为 1.9.0。增加环境数据、执行目标及 `SupportsPublicEnvironment`，旧构造器与执行注册签名保留为重载。Host 与插件须一起重建。

公开能力需要明确声明 `SupportsPublicEnvironment=true`；目录、facet 读取/写入及执行入口都检查边界。声明意味着维护者已核对其数据访问和输出目标，不是对任意第三方插件的进程级沙箱。表达能力还必须属于当前环境的身体。

当前接入本地对话、QQ 文字、环境内历史、Tavily 联网和配置可用时的 QQ TTS。其他旧能力默认仅私密可用，需逐项适配。通用绑定 API 支持其他平台，但其他平台仍需要实现结构化观察和固定目标发送。

只有已绑定本人能以 `source=user` 保存明确约定，且约定仍属当前环境；其他参与者不能冒认专属用户或修改私密约定。

## 配置和迁移

控制台“身份”页新增“在场环境”：绑定本人 QQ、填写跨环境共同自我描述、查看最新环境。接口为 `GET/PUT /environment/settings`，沿用控制台现有认证；保存 QQ 时保留其他平台的绑定。未绑定 QQ 时，QQ 单聊也按公开处理。

SQLite 增量增加环境字段，不删除旧记录。旧记录按私密处理，公开记录保留通用 user/assistant 角色及真实参与者来源；身份改名不将其改写为专属用户。

公开原文召回读取本环境最近 200 条、最多返回 10 条；同时可召回本环境认知、夜间回望及明确批准的当前版本认知，原始证据单独检查权限。公开经历通过独立待构建日期扫描和 `PublicExperienceLogic` 逐批整理，不混入私密事件与身份复盘。公开主动后台活动尚未开放：后台事件记录后跳过模型与发送，不借用私密目标。

## 验证

`ChatCheck --environment` 覆盖身份/受众组合、冒认、旁听、私密哨兵在真实 Agent 和润色装配中的隔离、目标及召回隔离、创建时目标、拒绝改投、重启、身份改名和解绑。`--existence` 同时检查共同身份、来源修订、连续情绪、切片与夜间落地。`--cognition-migration <Migration程序集>` 验证真实查询、全天分批与日构建补偿入口。
