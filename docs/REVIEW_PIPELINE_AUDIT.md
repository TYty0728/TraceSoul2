# 全复盘链的取舍与篇幅（0.1.66）

2026-10-23按事件、细节、认知、回望、身份、内心、榜单和轨迹概览逐层检查。问题不只在身份正文：此前存在细节仅提示200字但未校验、每件事使用整批原文、少量切片拼接旧段再压缩，以及部分字段被截断保存的入口。

原始经历与证据随真实新经历增加是正常存档；派生正文应表达相应层次的当前结果，不能把所有存档都逐条搬进正文。篇幅校验是最后防线，先确定对象、来源和需要表达的变化。

| 阶段 | 取舍和去重机制 | 篇幅与恢复 |
| --- | --- | --- |
| 事件观察 | 每项用不超过40字的主题和真实`source_moment_ids`限定一件事；对照候选事件最近3项进展，只记新事实、转折或结果，复述可不增加条目。同主题的新一次经历仍是独立事件。 | 每批最多12项，短句80字；来源缺失、批外引用或同批重复拒绝。超长只按对应原句和主题重写一次，长摘要不回传，合格字段保持。单条原文超过16000字停止，原件保留。 |
| 事件细节 | 每条只读取自己选择的原句，不再给每条同一整批对话。只记一两个有辨识度的细节或当时感受，不重述当天和关系史。 | 目标几十字、上限200字实际校验。超限草稿只作恢复记录，从原句重新取舍一次，持续不合格停止，不截断入库。合格草稿/已提交细节可恢复。 |
| 私密/公开认知 | 延续0.1.65写入前语义比较：同义新证据复用节点，实质条件变化形成修订，仅复述经历可不形成认识。领域、对象、范围、例外和反证保持区别。 | 全部原始经历按24000字/200条分批覆盖；单条认识600字，条件字段另行校验。私密检查点不重放已提交批次，公开按真实环境独立提交。 |
| 当天回望 | 少量材料从整天原始切片直接成稿；超过12片或完整材料超过16000字，都先分批提名、全局选择少数事件再写一篇。迟到材料按完整原件替换当前正文。 | 目标500字、上限1000字。取消小批次先写多段、拼接、把长文交回压缩的路径。失败保留待处理原件；旧段落留作历史，不参与新稿。已有单篇合格历史结果仍可直接发表；已有效旧成稿不因升级自动重写。 |
| 身份 | 延续0.1.65完整来源归并、含义/证据变化判断、需要改变时才成稿；成稿阶段没有旧正文，重复印证不必重写卡。 | 约300字、最多600字。分批/跨批归并、判断、草稿和提交可恢复。人工固定卡与人格档案受保护。详见[认识演化](IDENTITY_EVOLUTION.md)。 |
| 日终内心 | 仅看当天回望与当前心情/共同场景，不再提供旧内心叙述、关系视角及关注全文供续写。空关注数组明确清除旧碎片。 | 除120字叙述外，心情80字、关系视角200字、场景120字、关注最多3项/每项160字均在日终入口校验，重复碎片拒绝。无效输出不交给存储层截断；原有实时版本保护保持。 |
| 日榜/长期晋升 | 按候选指针比较，不改写原认识。全部候选参与有界分批选择，再排序；取消长期晋升任取前20条，取消把旧上榜原因作为新理由的写作素材。 | 日榜10项、其他层3项。拒绝重复/未知编号及超过60字的理由；认知标签保留完整条件，不再硬截80字。 |
| 白天轨迹概览 | 原件保留，近期最多40组且目录约4000字参与比较，较早独立事件保持原视图；每批新增记录仍按原预算处理。 | 每句60字，限制输出数量与重复句；纠正不附失败正文。避免一天越长就把全部滚动正文不断交回模型。 |

事件来源映射与事件结果在同一检查点事务保存。升级读取旧事件草稿/检查点时仍保留原有整批来源范围，不猜测历史每件事的精确来源，也不覆盖已完成细节；新生成事件使用逐项映射。升级本身不会自动清理历史长条目。

旧`dedupe-cognitions`命令按文字归一化及Jaccard相似度合并认知，未能证明对象、范围和反证一致，现明确停止执行。存量认识可使用[身份重整预览](IDENTITY_REORGANIZATION.md)形成当前认识；这不删除或批量改写认知图。普通自动复盘不调用旧合并命令。

## 验证及边界

使用临时库与模拟模型，不消耗正式API、不联系QQ用户、不部署服务器、不解除日构建暂停，也不改正式角色资料。

- 实际Migration验证逐项来源、批外/缺失引用拒绝、细节3000字及201字失败、恢复只重写一次且不携带长草稿、合格细节零请求复用；原有批次事务、跨实例恢复及260条来源保护保持通过。
- 回望覆盖少量材料超长拒绝、持续超长保留待处理原件、重开数据库恢复、3条大切片先选后写、迟到原件重形成、旧1012/2153字材料留历史而不再压缩、成稿期间新来源拒绝，以及连续30日输入不接旧稿。
- 实际日榜150项全部参与比较，末项可入围、完整条件保留、输入有界；榜单重复/未知编号与超长理由拒绝。
- 183项轨迹概览验证近期窗口有界、早期视图与全部原件保持。日终内心所有文本及关注字段的越界、重复均拒绝。
- Release全解决方案、完整ChatCheck/Prompt与实际Migration回归通过；构建有24项既有相机测试类型冲突警告，0错误。公开发布与包验收另见[版本记录](RELEASES.md)。

语义是否同义、何者重要、是否有真实新变化仍由模型判断，程序不能证明任意API返回的语义结论正确。这里验证的是来源隔离、取舍顺序、预算、重复写入与恢复控制；真实模型的长期表现仍须在升级后观察。新经历原件仍会增加，不能通过删证据或合并反证来伪造“不增长”。
