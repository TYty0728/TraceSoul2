## 原因与修复

Agent 按变化输出字段，旧消费者却将省略关注视为清空，情绪还依赖额外 mood_changed。程序现在保存本轮实际出现的状态字段，跨行动轮合并后传入写回与持久快照；省略关注保留原始年龄，空字符串/“无”明确清除，正常六小时存活期保持。mood 新值直接更新，兼容布尔值由程序推导；关注解析、写入和视图统一最多三项。

控制台使用主体视图和同样的有效关注筛选；旧 beat/note 等不再占据 Agent 判断卡。显示实际 step、更新项、情绪、新增经历、新识、已提交目标变化和实际执行回执；中间步骤目标也保留。快照新增 agent_decision，重启后不会只剩旧 Mind 字段。没有输出的感受不会补造成所谓完整推理。

今日新识的存储链仍有效。此次为 new_fact 补齐语义：当前新得知、有真实对话或执行结果依据的信息，不能将自己的感受和愿望当事实。页面和实时状态读取完整当日条目；无新信息时允许为空。

## 轨迹数据链

- 每轮 today 表示新增片段，最多500字；day_trajectory_entries 按真实来源追加，而不是500字整天滚动替换。来源校验、按来源去重、写入事务保证跨会话拒绝与重放不覆盖。
- 从旧 runtime_slices 与 turn_reviews 的 today 恢复已有记录，保留旧 day_trajectory 摘要。恢复条目使用原来源的时间与环境；旧摘要只有最后一次更新时间，不能据此推断每件事的具体时间。原始聊天或旧快照已经删除的内容不能保证恢复。不会读取下载目录作为生产数据，更不会调用模型补造旧经历。
- 北京时间04:00切日，以来源发生时间归属日期；轮次保存跨过边界也不会被归入错误日期。读取、注入和页面沿用同一记忆日。
- RuntimeContext、TimeScheduler、Host、IdleDeed、NightResidue、Migration 的日构建与监视读取统一入口。主实时状态/页面读取全体条目；闲暇/余温保留原有取材长度限制，原件和日构建输入不受这些视图限制影响。
- 日终成功只标记退出目标日实时视图，不删除轨迹原件。切片夜间复盘保留原有来源与成功提交规则；不修改潜意识/身份复盘算法。
