## 首次配网

1. USB连接电脑，桥以`--port <COM口> --connection-config <仓库外私密目录>/wifi-client.json`启动。`Start-Panel.ps1`自动使用所指定运行目录的配对文件。
2. 在5089本机控制页展开「Wi-Fi 配网与连接」，填写2.4GHz网络名称和密码，点击「保存Wi-Fi并重启开发板」。当前仅接受WPA2/WPA3、8～63字节密码；SSID最多32个UTF-8字节。电脑可以有线联网，但需与板子局域网互通。
3. 保持USB，稍候点击「检查Wi-Fi状态」。取得IP不代表无线控制已验收；再点「切换到Wi-Fi控制」，验证设备证书与独立令牌后才保存连接方式。
4. 用屏幕文字和测试音验证无线输出，再换充电宝供电，等待板子重新联网后再次验证。首次恢复可先检查连接，未知结果不自动重播。

Wi-Fi密码只经本机页面和USB写入板子NVS，不保存在电脑配对文件、不返回网页状态，也不作为命令行参数。电脑配对文件保存设备证书、私钥、独立令牌、地址和连接方式，使用受限权限原子写入，必须位于仓库外。NVS尚未启用Flash加密，配对后的整片固件备份也应视为私密数据，不上传源码。

## 链路与边界

```text
TraceSoul Host → 回环5089桥 → TLS设备证书校验＋独立令牌 → Wi-Fi开发板
                    ↓
            电脑本地ASR／声纹／TTS
```

每条完整命令或采音流独占一次TLS连接，播放/采集期间保持连接；完成后关闭，下一次重新认证，避免长时间静置或更换供电后复用旧socket。错误证书、错误令牌、断线与未知完成状态不降级到明文、不自动切回USB、不自动重播。USB与无线端的硬件操作互斥。

这是局域网第一版；不监听电脑公网地址、不自动开放防火墙、不做端口映射，也未新增公网网关。切换手机热点或更换路由器需重新配网；目前没有mDNS发现，DHCP地址改变时需接回USB、切USB模式，再切Wi-Fi读取新地址。可在路由器保留租约。访客网络或AP客户端隔离可能阻断电脑与板子。

本阶段开机显示本机主页和联网状态，不会自动开始监听；触屏用于本机菜单，不自动提交触觉Moment。是否进入语音会话仍由Host明确控制。充电宝仅供电，模型与主体仍需可达的电脑/服务器。Wi-Fi不等于移动蜂窝网络。
