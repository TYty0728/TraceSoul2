## 发布门禁与验收边界

本机没有 Docker，因此本候选尚未执行真实容器内升级。`release.yml` 的 release job 依赖 `update-integration` 成功；必须让新候选通过该门禁，不能用 0.1.15 的历史成功代替。Linux 包已完成交叉发布和内容校验，未在本机执行其二进制。

本轮未启动真实 Host、调用真实模型、向真人发送消息、读取或迁移正式数据库、补跑历史日构建。真实模型形成认知的质量和外部环境实机行为仍需运行观察；旧表升级与事务边界由临时数据库回归覆盖。

产品版本和版本说明已更新至 0.1.16，完整 ChatCheck 包含联网专项。下一步按已验证范围提交并触发发布 CI，再核对公开资产与更新入口；未经门禁成功不得报告发布完成。
