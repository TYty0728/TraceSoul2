## 网页操作

在「身体与感官 → 小智开发板 → 名字唤醒与听写校正」设置：

- 规范名字：未显式配置时读取角色名字；这里只配置听写与唤醒，不重命名角色身份。
- 按读音匹配：默认启用，从规范名字生成不带声调的拼音。“小汐”→`xiao xi`，“阿循”→`a xun`，无需枚举“小溪、小希、小西、晓曦”等同音字。只比较完整音节，不把`xu`、`xun`或`xing`等自动模糊合并。
- 匹配读音：留空自动生成，可手动指定多音字，如`hang hang`；支持配置带音调字母或数字后归一。修改名字时网页清空旧读音，保存后重算。预览也支持空格分隔的拉丁拼音文本，如`xiao xi`，不跨标点拼接音节。
- 其他误识别：可选，逗号、顿号或换行分隔，最多16项。供非同音误识别使用，如“阿旭”=`a xu`与“阿循”不同音，但可明确作为特殊变体；阿循未配置变体时默认提供阿旭。同音无须填写；空变体列表仅关闭这些特殊映射，不关闭拼音。
- 唤醒应答：默认“诶，我在。”，通过当前开发板语音配置播放。
- 文本预览：使用已保存规则，无采音、无模型调用、无 Moment 写入。

规则在听写完成后单次替换，不改变 ASR 模型权重。按称呼语境匹配，如“小希你好”→“小汐你好”；普通名词样例“河边有一条小溪”“小溪里有鱼”保持不变。启发式规则不能消解所有歧义，应先预览。关闭拼音后可只使用明确变体。

当前是“音频→本地ASR文字→逐字拼音→称呼匹配”，不是直接从音频运行KWS声学唤醒；ASR无结果或读音也识错时不能恢复。中文逐字转换采用固定版本[TinyPinyin.Net 1.0.2](https://www.nuget.org/packages/TinyPinyin.Net/1.0.2)，[上游接口与单音默认读法](https://github.com/hstarorg/TinyPinyin.Net)；候选文字的多音字暂按字典默认读音，不进行语义消歧。规范名可手动纠正读法。

手动听写和连续通话共享规则；正文采用校正后的名字，真实语音事件载荷保留 `raw_transcript` 和 `name_corrected`。手工输入不自动改写，也不能冒充板载听写。

## 交互状态

1. 用户点击连接：开启名字监听且已录入本人声纹时，本页自动开始监听；未录声纹时仅连接，先完成录入。也可用「开始名字监听／暂停监听」控制。
2. 发呆：USB采音、VAD、本地ASR运行；没有命中名字的发言不产生对话、不调用 JEV 或主模型。
3. 唤醒：只叫名字时显示并播放简短应答，进入30秒专注窗口。名字连指令时先应答，通过本人声纹后才取得一次性对话凭据。
4. 专注：本人后续发言无需再叫名字，经声纹确认后进入 `hearing / wxxz` Moment，沿原会话回复。有效发言及回复完成后重新计算30秒；处理/播音期间暂停采音。过期回到等待名字，截止前开始的发言允许说完。
5. 停止：明确点击暂停，撤销注意力与准入，取消采音；停止后迟到结果不再发送，已开始的输出可能收尾。后台版刷新/离开页面不结束监听，重开后附着原任务；Host重启后需重新开始。

短名字可能不足 CAMPPlus 当前1.2秒有效语音要求，因此允许没有声纹证据的短名字触发固定应答；**这不是本人确认**。进入主模型的实际指令仍要求原整句声纹门槛，不以名字或非空听写替代。目前不分离多人混说。

纯名字与固定应答只记运行事件，不制造主模型对话；实际指令仍是一条听觉输入。应答失败终止本页循环，不自动重放。应答沿用现有 TTS 链路，尚无固定应答预生成缓存。

设备30秒专注与 Soul 持久心智状态分开，不更改睡眠/空闲/心跳策略。未来视觉注意力入口需沿用此边界，本次没有摄像头或视频触发。

后台版由Host任务逐句驱动，网页只观察和控制。连接可能开始采音，关闭网页不等于暂停；暂停并收尾后才能改称呼、录声纹或试听音色。输入框有未发送内容时先发送或清空，避免覆盖。

## 接口与保存

- `GET /wxxz`：配置 `wake` 与动态 `attention`。
- `PUT /wxxz/wake`：保存 `enabled/name/phonetic/pronunciation/aliases/reply`，监听中拒绝修改。
- `POST /wxxz/wake/preview`：`{text}` 返回原文、校正结果、名字命中、是否纯唤醒、`pronunciation`与`matchMode`（phonetic/alias/literal/none）。
- `POST /wxxz/call/start`：新增 `wake`，旧客户端未传时维持原显式通话。
- `POST /wxxz/call/listen`：新增 `standby/wake_ack`，只有 `verified` 返回对话凭据。

接口沿用控制台鉴权。角色 `wxxz/wake.json` 原子保存，不改已有三段声纹；旧配置缺少读音字段时默认启用自动拼音，保留原明确变体。桥 `/api/utterance` 在短句无声纹时也可返回 ASR 文字，附语音起点和采音时长，由 Host 判定准入。升级必须同步TinyPinyin.dll与Host.deps.json，外层本地脚本已覆盖；不能只热换HTML或Host DLL。
